# Geometric Lib

## Общее описание решения

Библиотека для вычисления площади и периметра разных геометрических фигур: круга, квадрата, прямоугольника и треугольника.

### Математические формулы

**Area (площадь):**
- Circle (круг): S = πR²
- Rectangle (прямоугольник): S = ab
- Square (квадрат): S = a²
- Triangle (треугольник): S = ah/2

**Perimeter (периметр)**
- Circle (круг): P = 2πR
- Rectangle (прямоугольник): P = 2a + 2b
- Square (квадрат): P = 4a
- Triangle (треугольник): P = a + b + c

## Описание функций

### Файл circle.py

#### area(r)
Принимает радиус r, возвращает площадь круга с радиусом r.
Пример вызова: `area(10)` => 314.1592653589793

#### perimeter(r)
Принимает радиус r, возвращает периметр круга с радиусом r.
Пример вызова: `perimeter(10)` => 62.83185307179586

### Файл square.py

#### area(a)
Принимает сторону a, возвращает площадь квадрата со стороной a.
Пример вызова: `area(10)` => 100

#### perimeter(a)
Принимает сторону a, возвращает периметр квадрата со стороной a.
Пример вызова: `perimeter(10)` => 40

### Файл rectangle.py

#### area(a, b)
Принимает стороны a и b, возвращает площадь прямоугольника.
Пример вызова: `area(5, 10)` => 50

#### perimeter(a, b)
Принимает стороны a и b, возвращает периметр прямоугольника.
Пример вызова: `perimeter(5, 10)` => 30

### Файл triangle.py

#### area(a, h)
Принимает сторону a и высоту h, возвращает площадь треугольника.
Пример вызова: `area(5, 10)` => 25.0

#### perimeter(a, b, c)
Принимает стороны a, b, c, возвращает периметр треугольника.
Пример вызова: `perimeter(5, 10, 15)` => 30
